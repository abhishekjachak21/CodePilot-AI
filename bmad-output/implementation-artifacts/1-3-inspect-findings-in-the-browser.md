# Story 1.3: Inspect findings in the browser

## User story
As a Java developer, I want findings presented with severity and remediation, so that I can understand and act on feedback.

## Acceptance criteria
1. Finding cards show category, severity, title, line, explanation and suggested fix.
2. Illustrative corrected code can be copied.
3. Loading, error, findings and no-findings states are understandable.
4. UI warns that heuristic analysis is incomplete.

## Verification plan
Verify desktop/mobile layout and clipboard behavior.

## Status note
Source code for an initial slice exists in the repository. This story remains ready-for-dev until its acceptance criteria are verified locally.
